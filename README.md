# Musubi

An interactive web experience exploring memory, longing, and the viral image — after Makoto Shinkai's *Your Name* (君の名は, 2016).

Two worlds sit divided on screen: Taki's Tokyo and Mitsuha's Itomori, separated by a thin line of light. Click to surface memory fragments. Watch a red thread slowly draw between them. The two worlds merges but Taki and Mitsuha doesn't end in an embrace — that gap is the argument.

---

Created as a Creative Project for **Arts 1** at the **University of the Philippines Diliman**.
